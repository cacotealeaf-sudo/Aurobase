AUROBASE資安與資料處理

資料留在您手上 每一步都查得到.

金融與受監理產業評估 AURO NEXUS 時，資訊、資安與法遵單位最常問六件事：資料放在哪裡、誰能存取、個資怎麼保護、紀錄能不能被改、資料保存到何時，以及軟體元件從哪裡來。以下逐項說明做法，並連到對應的產品頁。

// 01 — 六項做法

平台怎麼處理資料

// 部署

資料留在哪裡

  • 可部署於公有雲的台灣區域、企業自有機房或隔離網路，三種方式使用同一套權限、模型路由與稽核軌跡。
  • 模型路由可限定只使用地端模型，資料不需送出企業環境。
  • 隔離網路中，弱點情資等需要更新的資料以離線更新包匯入。
平台部署方式Forge
// 存取控管

誰能用、能查什麼

  • 每一次 AI 請求在送往模型之前先做權限與政策檢查，不符合的請求不會到達模型。
  • 知識庫與段落可設定密級，依擁有者、使用者、角色、服務分別授權；跨租戶一律拒絕。
  • 撤銷權限在下一次檢索就生效，不靠快取過期；資料庫以列級安全（RLS）做租戶隔離。
  • Scanner 支援 SAML 2.0 單一登入與 SCIM 帳號同步，SAGA 支援 Kerberos 與 LDAP 群組綁定；與貴機構既有身分系統的介接由奧洛團隊配合調整。
ForgeScannerSAGA
// 個資保護

個資不外流

  • 提示中含身分證字號、電話、電子郵件或密鑰時，自動提高敏感等級，只能送往地端模型；送雲端會被拒絕並留下紀錄。
  • 模型的回覆也經政策檢查，不合規即改為遮蔽。
  • 以自然語言查詢資料時以唯讀身分執行，結果做個資遮罩後才回傳。
  • 個資刪除請求在稽核紀錄中就地遮罩，雜湊鏈仍可驗證。
Forge
// 稽核軌跡

紀錄有沒有被改過

  • 每一次推論、知識庫查詢與工具呼叫寫入雜湊鏈稽核軌跡，資料庫層拒絕修改與刪除。
  • 證據包可依關聯編號或審批編號匯出，附離線驗證工具，稽核人員不需連上平台就能重算雜湊。
  • 匯出權限只給稽核人員與管理者，每次匯出本身也寫入稽核帳。
  • 雜湊鏈能偵測竄改；要在物理上阻止擁有資料庫最高權限的人修改，需在儲存層加上 Object Lock。
ForgeSAGA
// 保存與銷毀

資料保存到哪一天

  • 依媒體類型設定保存期限，預設值依貴機構政策調整；保存期限未到，伺服器拒絕銷毀。
  • 法律保全中的紀錄只能釋放保全，不能直接銷毀。
  • 敏感變更需第二人簽核，提案人不能自己核准。
  • 銷毀證明含簽核鏈與雜湊，可離線驗證。
SAGA
// 軟體供應鏈

用了哪些元件、怎麼通報

  • 交付的平台元件可附 CycloneDX 與 SPDX 格式的軟體物料清單（SBOM）。
  • 貴機構自有系統可用 Scanner 做源碼檢測、弱點掃描與第三方套件分析，輸出 SARIF 報告與 SBOM。

平台總覽

金管會〈金融業運用人工智慧（AI）指引〉以治理與問責、隱私與客戶權益、系統穩健與安全、透明與可解釋等原則為架構。AURO NEXUS 以推論前檢查、地端模型、雜湊鏈稽核軌跡與可離線驗證的證據包對應這些原則。

平台提供的是這些做法的執行與紀錄；是否符合法規，由主管機關與貴機構法遵認定。
