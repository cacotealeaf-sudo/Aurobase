DEFINITION

源碼檢測、弱點掃描和 SBOM 有什麼不同？

源碼檢測（SAST）在程式上線前分析原始碼；弱點掃描（DAST）從外部測試執行中的網站與服務；SBOM（軟體物料清單）則列出系統用了哪些第三方元件，用來追蹤已知弱點。三者互補，缺一就會有盲點。

Scanner 是奧洛（Aurobase）AURO NEXUS 產品家族的源碼檢測與弱點掃描平台，把 SAST、DAST、SCA、機密外洩、容器與 IaC 掃描收進同一套權限與報告，輸出 SARIF 2.1.0 與 CycloneDX／SPDX 格式的 SBOM，並以 NVD、CISA KEV、EPSS 情資協助排序修補。

適合誰

  • 資安與應用程式安全團隊要把分散的掃描工具與報告收斂成一份清單。
  • 開發與 DevOps要在程式碼平台與編輯器裡直接看到結果並修正。
  • 委外與採購管理要求供應商交付 SBOM 與掃描報告時，需要一致的格式。

THE PROBLEM

弱點管理最花時間的是整合結果

多數組織不缺掃描工具，缺的是把結果收斂成一份能追蹤、能交代的清單。

01

工具各自為政

原始碼、套件、容器、網站各有一套工具與格式，彙整全靠人工，同一個弱點在不同報告裡重複出現。

02

套件清單說不清楚

被問到「系統裡用了哪些第三方元件、哪些有已知弱點」時，很難在短時間內拿出完整而一致的軟體物料清單。

03

優先順序靠感覺

弱點數以千計，缺少「是否已被實際利用」「被利用的機率」這類情資，修補排序只能憑經驗判斷。

Scanner 把各類掃描放進同一個平台，以標準格式輸出，並用公開威脅情資為每一筆弱點補上修補順序的依據。

CAPABILITIES

六類掃描，一套交付

掃描以佇列非同步執行，大型專案不會卡住介面；每次掃描的觸發者、範圍與結果都留有紀錄。

原始碼與套件

  • SAST 靜態原始碼分析。
  • SCA 第三方套件與授權分析。
  • 機密外洩偵測：找出寫死在程式碼裡的金鑰與憑證。

網站與服務

  • DAST 動態網站掃描。
  • 網路服務探測與已知弱點樣板比對。

容器與基礎設施

  • 容器映像弱點掃描。
  • IaC 基礎設施設定檔（如 Terraform、Kubernetes 設定）檢查。
  • Kubernetes 工作負載姿態（12 條規則，對應 CIS 與 Pod Security Standards）與叢集治理稽核。

主機與 Windows 修補

  • 以 Nmap 取得服務版本後比對 NVD 受影響版本區間，結果標示為推論並分三級可信度。
  • Windows 主機讀取作業系統組建版本，比對微軟修補梯級找出缺漏修補。

標準格式輸出

  • SARIF 2.1.0：可直接匯入開發工具與程式碼平台。
  • SBOM：CycloneDX 與 SPDX 兩種格式。

威脅情資同步

  • NVD、CISA KEV、EPSS 每 6 小時同步，零時差公告每小時更新；可再查詢 OSV、GitHub Advisory 等來源。
  • 以「是否列入已遭利用清單」與「被利用機率」協助排序修補。

權限與身分整合

  • 角色權限控管與多租戶隔離。
  • SAML 2.0 單一登入、SCIM 帳號同步。
  • 提供 VS Code 擴充套件，讓開發者在編輯器內看到結果。

合規對照與整合

  • 發現項目對照約 40 種框架，包括 OWASP Top 10、CWE Top 25、ISO 27001:2022、PCI DSS v4。
  • 第三方套件分析涵蓋 pip、npm、go、cargo、composer、nuget、rubygems 七種套件管理器。
  • 修補追蹤可送 Jira、ServiceNow，事件可推送 Splunk、Elasticsearch。

BEFORE YOU START

導入前提

以下事項會在導入前，依貴機構的環境與需求逐項確認。

1

威脅情資需要連線更新

NVD、CISA KEV、EPSS 等情資以網路同步；完全隔離網路的環境以離線更新包匯入，更新週期依貴機構規定設定。

2

部分第三方掃描工具依授權條款另行提供

個別開源掃描工具的授權條款不允許隨商用產品散布，此類工具依客戶環境與授權另行安裝。

3

主機 CVE 為版本比對推論

主機掃描的 CVE 依服務版本推論，未經實際利用驗證；發行版已向後移植修補的套件可能誤報，報告會調降可信度。

FAQ

常見問題

SBOM 是什麼？

SBOM（Software Bill of Materials，軟體物料清單）列出一套軟體使用的所有第三方元件與版本，用來追蹤已知弱點與授權。Scanner 可產出 CycloneDX 與 SPDX 兩種格式的 SBOM。

源碼檢測和弱點掃描差在哪？

源碼檢測（SAST）在上線前分析原始碼；弱點掃描（DAST）從外部測試執行中的網站與服務。Scanner 兩者都涵蓋，另有第三方套件、機密外洩、容器與 IaC 掃描。

弱點的修補優先順序怎麼決定？

平台定時同步 NVD、CISA KEV、EPSS 等公開情資，為每筆弱點補上「是否已遭實際利用」與「被利用機率」，作為修補排序的依據。

掃描結果可以匯入開發工具嗎？

可以。結果以 SARIF 2.1.0 輸出，可匯入程式碼平台與 CI 流程；另提供 VS Code 擴充套件。

可以接公司既有的帳號系統嗎？

可以。Scanner 支援 SAML 2.0 單一登入與 SCIM 帳號同步，並提供角色權限與多租戶隔離。

想先掃一個專案看看？

我們可以挑一個代表性的專案，跑一次完整掃描，交付 SARIF 與 SBOM 報告。
