DEFINITION

企業的 SSL 憑證該怎麼管理？

三件事：找得到（完整清冊）、檢查得了（弱金鑰、效期、信任狀態）、換得過去（到期前自動更新並驗證）。公開憑證的效期正逐步縮短，人工追蹤已經跟不上。

Cardea 是奧洛（Aurobase）AURO NEXUS 產品家族的 SSL 憑證管理與機器身分治理平台。它自動盤點 TLS 憑證與 SSH 金鑰，依政策檢查並在到期前預警，以 ACME 自動更新並部署至 Nginx、Apache、IIS，產出密碼演算法分布報告作為後量子密碼遷移的盤點基礎；可單機、離線運作。

適合誰

  • 維運與網管要擺脫用試算表追蹤憑證到期。
  • 資安長與資安單位要掌握全公司的憑證、金鑰與演算法現況。
  • 金融機構要啟動後量子密碼遷移的第一步：密碼技術盤點。

THE PROBLEM

憑證管理的老問題

01

不知道有多少張

憑證由不同團隊在不同時間申請，沒有一份完整清冊，總有幾張是沒人記得的。

02

到期靠行事曆

到期提醒靠人工記錄與試算表，人員異動後就斷了，最後由服務中斷來提醒。

03

效期越來越短

公開憑證的最長效期正逐步縮短，更新頻率提高，人工作業已經跟不上。

Cardea 把憑證與 SSH 金鑰當成要治理的機器身分：盤點、檢查、預警與更新，每一步都留下紀錄。

CAPABILITIES

核心能力

盤點與探索

  • 平行掃描網段與服務，建立憑證清冊。
  • 可匯入既有網段掃描、CMDB 與憑證透明度（CT）資料。
  • SSH 金鑰盤點。

政策檢查

  • 弱金鑰、禁用簽章演算法、自簽、過期、非允許 CA、已失信 CA。
  • 依 CA/Browser Forum 公布的效期時程判定效期是否超標。
  • 本國 CA 信任狀態偵測。

密碼敏捷度

  • 密碼演算法分布報告，作為後量子密碼（PQC）遷移規劃的基礎。
  • 憑證透明度（CT）日誌監控，發現非預期簽發。

到期預警與漂移偵測

  • 到期前依門檻預警，可通知 ServiceNow、Jira 或 Webhook。
  • 漂移偵測：線上服務的憑證與最後一次部署的不一致時告警。

簽發、部署、驗證

  • 透過 ACME 協定簽發，可接內部 ACME CA。
  • 部署至 Nginx、Apache（SSH）與 IIS（WinRM）。
  • 部署後自動驗證線上憑證。

權限與稽核

  • 角色權限控管、自助申請與審核、變更窗口管制。
  • 雜湊鏈稽核軌跡，截斷或清空都偵測得到。
  • 唯讀 REST API 供其他系統查詢。

指引面向Cardea 的對應做法
密碼技術盤點自動盤點 TLS 憑證與 SSH 金鑰，產出密碼演算法分布報告。
風險排序依政策標出弱金鑰、禁用簽章演算法、效期超標、非允許與已失信的 CA。

測試切換部署後自動驗證線上憑證；漂移偵測發現線上與部署紀錄不一致。

WHAT'S DIFFERENT

差異點

單機就能跑

設備形態部署，不需要外部資料庫或雲端服務，隔離網路內也能完成盤點、檢查與預警。

為後量子遷移做準備

密碼演算法分布報告讓您知道哪些系統還在用哪些演算法，PQC 遷移有盤點基礎。

竄改可被偵測

稽核軌跡以雜湊鏈與錨定保護，紀錄被截斷、清空或改寫都偵測得到。

客製

部署目標與通知

依貴機構的設備與 CA 調整簽發與部署方式；預警可接 ServiceNow、Jira 或 Webhook。

SCOPE

範圍界定

部署目標依設備逐一驗證

FAQ

常見問題

SSL 憑證到期要怎麼查？

單一網站可用瀏覽器或命令列查看；企業內數十到數千張憑證則需要自動盤點。Cardea 平行掃描網段與服務建立清冊，到期前依門檻預警，並可通知 ServiceNow、Jira 或 Webhook。

憑證可以自動更新嗎？IIS 也可以嗎？

可以。Cardea 透過 ACME 協定簽發，部署至 Nginx、Apache（SSH）與 IIS（WinRM），並在部署後自動驗證線上憑證。

後量子密碼遷移要從哪裡開始？

從密碼技術盤點開始：先知道哪些系統用了哪些演算法與金鑰。Cardea 產出密碼演算法分布報告，作為後量子密碼（PQC）遷移規劃的盤點基礎。

可以在沒有網路的環境使用嗎？

可以。Cardea 以單機設備形態部署，不需外部資料庫或雲端服務，盤點、政策檢查與預警都能在隔離網路內完成。
